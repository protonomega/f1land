## 1. Визуальный тезис

> **«Ночная гонка под софитами».** Данные лежат в тихой темноте. Свет появляется только там, где происходит действие: выбранный исход, кнопка подтверждения, живая трасса, момент выигрыша.

Из этого следуют три правила:

1. **В данных тихо, в моментах ярко.** Списки, таблицы и тайминг остаются нейтральными. Hero-блоки, выбор исхода, CTA и празднования получают арт, свет и движение.
2. **Арт за контентом, а не вместо него.** Изображение лежит фоном под затемнением (scrim). Текст и цифры поверх всегда остаются HTML: никакого текста в картинках.
3. **Каждой механике свой мир.** У девяти семейств пулов девять разных hero-сцен и инфографик, а не одна карточка с разными словами.

## 2. Цвет и «бюджет света»

Существующие токены в `src/styles/app.css` (`:root`) сохраняются. Нужно добавить семантику и правила.

| Роль | Токен | Где можно | Где нельзя |
|---|---|---|---|
| Действие, выбор, «твоё» | `--lime #c6ff3d` | Основная кнопка, выбранный исход, свой пилот, активная вкладка, «следующая сессия» | Декоративные рамки, иконки разделов, фон списков |
| Эфир, ошибка | `--red #ff3b47` | LIVE, красный флаг, ошибка, срочный таймер (≤10 с) | Акценты без смысла |
| Внимание | `--yellow #ffd12e` | SC/VSC, жёлтый флаг, рейтинг и кубки | — |
| Лучшее время | `--purple #b26bff` | Fastest lap, лучший сектор (конвенция F1) | Другое |
| Соперник, инфо | `--cyan #2fe6ff` | Rival, информационные подсказки | Таймеры и CTA |
| Команды | `TEAM_BY_ID[...].color` | Только идентификация пилота: риска, обводка шлема, тинт карточки пилота | Фон крупных блоков |
| Сектора | `SECTOR_COLORS` = S1 `#c6ff3d`, S2 `#2fe6ff`, S3 `#b26bff` | Трасса, плитки зон | — |

**Бюджет света (обязательно):**
- Светиться может только: (а) выбранный исход, (б) основная CTA, (в) линии трассы и маркер выбранного пилота на схеме, (г) момент выигрыша или повышения уровня.
- В видимой области не больше **одного** светящегося UI-элемента, не считая трассы.
- Свечение направленное, сверху вниз, с цветным тинтом. Ореол со смещением 0 — запрет impeccable.

```css
/* app.css :root — добавить */

--lime-lo: #a8ec22;           /* низ градиента CTA */
--glow-lime: 0 10px 28px -10px rgba(198, 255, 61, 0.55);
--glow-sel: 0 8px 22px -10px rgba(198, 255, 61, 0.5);
--rim: inset 0 1px 0 rgba(255, 255, 255, 0.07);      /* верхний блик панели */

--scrim-l: linear-gradient(90deg, rgba(7, 9, 11, 0.92) 0%, rgba(7, 9, 11, 0.55) 55%, rgba(7, 9, 11, 0) 100%);
```

## 6. Движение и микровзаимодействия

Токены (добавить в `:root`):

```css
--dur-1: 120ms;  /* мгновенный отклик */
--dur-2: 200ms;  /* смена состояния */
--dur-3: 320ms;  /* шторка, смена вида */
--dur-4: 560ms;  /* авторский вход, один на экран */
--ease-out: cubic-bezier(0.16, 1, 0.3, 1);
--ease-in: cubic-bezier(0.4, 0, 1, 1);
```

## 11. Как проверять (обязательно на каждой фазе)

1. `pnpm typecheck && pnpm test` (сейчас 541 тест) и `pnpm e2e` (24 сценария; полный прогон ~5 мин, запускать в фоне: `setsid nohup ... &`).
2. Сборка с хуками для e2e: `VITE_E2E=1 pnpm build && pnpm preview --port 4173`.
3. Скриншоты: `node dev/shot-app.mjs --url http://127.0.0.1:4173/ --dir <out> --w 390 --h 844 --lang ru --only home,races,live,pools,profile,pool:zone,pool:duel,pool:pit,pool:tyre,pool:pace,pool:incident,pool:position,pool:quali,pool:combo`. 3D в headless медленный, для пулов ставить `renderMode: '2d'`.
4. Переполнения: `node dev/scan-overflow.mjs` (320 и 360 px, RU и EN). Новых обрезаний быть не должно.
5. Детектор impeccable: `impeccable detect --json <изменённые файлы>`. Скилл: https://github.com/pbakaus/impeccable, перед правками UI читать `reference/craft-floor.md`.
6. Reduced motion (`settings.motion = 'reduced'`), ширины 320/360/390/430, языки RU и EN, safe-area 34 px (`--tg-safe-bottom`).
7. Производительность: Chrome DevTools, 4× CPU и Slow 4G. LCP < 2.5 с, после загрузки нет long tasks > 200 мс, 60 fps при переключении вкладок.
8. **Визуальная приёмка:** положить новый скриншот рядом с референсом той же механики. Если неясно, что сделано лучше, работа не закончена.

## 12. Ограничения (нарушать нельзя)

- **SRS:** прогнозы не зависят от приблизительных позиций в 3D/2D; тайминг, порядок и классификация раздельны; метка DEMO; никаких выдуманных метрик и «инсайтов» без расчёта из событий сессии.
- **Права:** никаких лиц реальных пилотов, логотипа F1, логотипов команд и спонсоров (детали в 03, §1).
- **Деньги:** только DEMO PULSE. Никаких USDT и знаков валют.
- **Telegram WebView:** без фоновых видео, без тяжёлых шейдеров в 2D-режиме. Изображения над сгибом ≤ 250 КБ, вес всех ассетов ≤ 6 МБ, грузить лениво.
- **Доступность:** контраст текста ≥ 4.5:1, в том числе поверх арта (scrim обязателен). Зоны нажатия ≥ 44 px. У декоративного арта `alt=""`, у смысловых объектов есть подпись.
- **i18n:** весь текст в словарях RU и EN; в картинках текста нет.
